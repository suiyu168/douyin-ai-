# 成蹊云 CRM（本地演示切片）

> **仅限虚构数据演示。不得输入真实姓名、手机号、身份证号、支付信息或任何真实个人资料。**

这是一个可运行的本地 SQLite 业务切片，用来演示客户去重、权限范围、订单资金台账、AI 风险转人工和客服工作台。它不是生产 CRM，也不是最终的云端部署。

## 前提与启动

需要 Node.js 24 或更高版本（内置 `node:sqlite`）。在仓库根目录执行：

```bash
npm run crm:start
```

默认打开 [http://127.0.0.1:4310](http://127.0.0.1:4310)。控制台出现 `CRM_READY ...` 表示迁移和虚构 seed 已完成，工作台可以使用。

运行测试：

```bash
npm run crm:test
```

也可用 `pnpm crm:start` 和 `pnpm crm:test`。

## 本地演示身份

工作台可选的固定虚构身份全部由服务端决定，浏览器无法提交角色或数据范围：

- `admin-1`（管理员）：查看本演示切片中的全部虚构客户、会话和订单。
- `service-1`（客服）：仅查看 `campus-a` 中负责人为 `service-1` 的客户及其会话。
- `finance-1`（财务）：只读查看本校区客户、订单和必要手机号；不能查看会话，也没有写入权限。

本切片的财务身份是只读的。付款、退款等资金写权限需要后续单独完成授权与审批决策，不能把当前演示当作可收款或可退款系统。

## 数据与配置

默认数据库在本机用户目录的 `~/.chengqiyun-crm-data/chengqiyun-crm.sqlite`，不在仓库内。首次启动会安全创建缺失目录；程序绝不会清空或删除已有目录。

可按需覆盖：

```bash
CRM_HOST=127.0.0.1 CRM_PORT=4311 CRM_DATA_DIR=/safe/local/crm-demo npm run crm:start
```

端口必须是 1–65535 的整数；主机不能为空且不得包含控制字符；数据路径必须是目录。在 POSIX/Unix 环境，按 `Ctrl+C` 或发送 `SIGTERM` 会先停止 HTTP 服务，再关闭 SQLite，一次且仅一次。Windows 本地控制台请使用 `Ctrl+C`；仅在 Node IPC 通道存在时，父进程可发送固定的 `{ type: 'crm:shutdown' }` 控制消息，供测试或托管父进程使用，HTTP 不提供该能力。

首次启动会用真实业务服务写入三名固定虚构学员及虚构合同、已确认/待处理资金流水和一条人工接管会话。所有写入均使用固定幂等请求号，重复启动或中断后的再次启动不会重复生成数据。

## 当前范围与限制

已实现：本地客户去重、服务端角色与范围控制、脱敏、追加式订单台账、审计、风险转人工、聚合仪表盘和同源工作台。

尚未实现：云端/ PostgreSQL 部署、生产身份认证、真实 FastGPT 接入、真实企业微信或微信连接器、文件材料上传和完整审批流。请不要把本地演示身份或 SQLite 文件用于生产。
