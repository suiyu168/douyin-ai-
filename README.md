# 成蹊云 CRM（开发中）与 douyinauto legacy 基线

成蹊云 CRM 正在 [`crm/`](crm/) 中开发，提供独立的本地业务演示切片。现有基于 Electron 的抖音图文发布与公开商务线索管理工具保留为 **legacy 基线**，用于参考和回归验证；其既有运行方式与脚本不随 CRM 开发改变。

双击 `启动抖音自动化.cmd` 可启动 legacy 开发版。

## douyinauto - 抖音图文发布助手（legacy）

## 商机雷达（多渠道版）

- 五类工程行业：地坪、冷库、膜结构、推拉棚/伸缩棚、无尘车间/净化工程。
- 组合地区与行业关键词，批量生成中国政府采购网、全国公共资源交易平台、政府立项/环评/补贴公示、高德地图和抖音公开搜索任务。
- 业务员主动打开公开页面后，可采集当前页面公开文字；也支持粘贴主页简介、作品文案、OCR 文字或公开评论。
- 内置 Tesseract.js 本地中文 OCR，可从主页截图、公告截图中提取文字和联系方式；模型默认位于 `D:\小V猫数据\抖音自动化\OCR`。
- 自动识别公开手机、座机和 400/800 商务电话，按行业、意向和来源位置评分并合并重复号码。
- 公开号码在本机界面和 CSV 中完整显示；SQLite 磁盘字段仍使用 Windows DPAPI 加密，拒绝联系后锁定并记录审计事件。
- 支持状态跟进、备注、来源链路、筛选和不截断的完整号码 CSV 导出。

商机数据库与导出文件默认保存在 `D:\小V猫数据\商机雷达`，不会写入 Git 仓库。系统不会自动评论、私信、群发，也不会获取隐藏联系方式。

当前版本按三条独立管线工作：

1. 低频读取已核验的官方招投标/公共资源公开页面，工程项目信息无论是否带联系方式都保留；正文存在公开联系方式时一并提取。
2. 在白天安全时段巡检五类厂家公开视频下的公开评论，只入库包含询价、预算、找厂家/施工队等明确需求的潜在客户评论。
3. 扩展检索五类行业的厂家、公司、安装、施工、改造、维修等账号组合词，进入公开主页核验；同时补全高意向评论者的公开主页，只有找到公开联系方式的主页才进入获客线索库。

系统不会绕过验证码、登录验证或访问限制。第三方视频的高意向评论只进入逐条审核队列，系统给出建议回复并打开原视频，不自动批量点赞、关注、评论、私信或群发；触发平台验证时只隔离对应账号并提示人工处理。

## 公开项目自动采集

- 默认每 6 小时低频读取 130 个已核验公开入口：政府采购公告分类、扩展行业关键词、全国及 31 省区市和新疆兵团公共资源交易入口、央国企/建设单位采购栏目，以及无需验证码的北京/广东/广西投资项目推介数据。
- 可另行启用真正的“搜索引擎发现层”：支持 Brave Search API 或本机/自建 SearXNG，按 330 组“行业 × 项目阶段 × 地区”组合词轮转检索最近 31 天公开网页。固定公开入口继续作为高准确率底座，不是唯一数据来源。
- 搜索服务的 API 密钥只在本机通过 Windows DPAPI 加密保存，不返回页面；陌生搜索结果只保存标题、摘要、日期和原链接，不会自动访问任意结果网址。搜索提供方未配置时，该层保持关闭，不影响其他采集任务。
- 采购意向、全国投资审批结果等需要验证码的公开查询页只保留人工入口，系统不会识别或绕过验证码。
- 省级入口采用独立目录与通用解析适配器：优先读取已核验的工程公告栏目，自动发现同域公告列表；每个入口最多读取 7 个页面，失败会记录健康状态并按 2—24 小时退避，国家平台继续兜底。
- “广泛发现”先排除中标、成交、废标、合同等结束类公告，再读取正文识别五类工程；“精准标题”只读取标题已命中行业词的公告。
- 当前版本只写入本机线索库，不会向任何外部系统同步数据。
- 中国招标投标公共服务平台的 `robots.txt` 明确禁止自动抓取，因此系统将其标记为“禁止采集”；其他入口只读取官方公开 HTTPS 页面，不跨域跟随、不绕过验证码。
- 采集器失败不会影响线索库或发布功能，失败记录保留在本地，便于检查后重新采集。
- 公告详情失败采用持久化指数退避，最多尝试 5 次；省级入口按每条路由分别记录正常、空结果、降级和错误，部分路由失败不会掩盖也不会阻塞健康路由。

## 长时间运行与数据保护

- 抖音采集固定在 `08:30—22:30` 运行，需求评论每 75—120 分钟增量巡检，厂家主页每 4—6 小时扩展检索；夜间硬暂停抖音访问。
- 24 小时守护可在商机雷达页开关。开启时防止 Windows 挂起自动任务，但不会取消抖音夜间安全门禁。
- 登录 Windows 后由计划任务 `抖音自动化-开机启动` 自动启动；异常最多重试 3 次，主进程和界面均有崩溃循环上限。
- 4 个 SQLite 业务库每天做完整性检查和可恢复快照，备份位于 `D:\小V猫数据\商机雷达\备份`，每库轮换保留 7 份；界面也支持“立即备份”。

## 功能

- 多账号一键发布（图文）：选账号 → 选图片 → 标题/正文/话题 → 音乐 → 发布
- 自动选音乐（从抖音音乐库搜索，按歌名匹配）
- 定时发布（本地定时，到点自动触发，兼容对象/字符串/时间戳）
- 任务记录（状态徽章 + 自动刷新）
- 账号管理（添加账号 = 弹窗扫码登录，自动提取 cookie 保存）
- Camoufox 防关联浏览器集成（外部浏览器打开账号环境）

## 运行

开发模式（需要 Electron）：在 `D:\抖音自动化` 运行 `npm.cmd start`，或双击根目录的 `启动抖音自动化.cmd`。

## 数据

- `D:\小V猫数据\抖音自动化\用户数据\state\accounts.secure.json`：账号元数据和经过 Windows DPAPI 加密的 Cookie。
- `D:\小V猫数据\抖音自动化\用户数据\state\publish-tasks.sqlite`：发布队列、批次幂等标记和中断恢复状态。
- Electron 登录分区、Camoufox资料和缓存：`D:\小V猫数据\抖音自动化\用户数据`。
- 商机数据库、完整号码导出和数据库备份：`D:\小V猫数据\商机雷达`。

## 调试

- 默认不开放调试端口；隔离验收时通过 `VCAT_REMOTE_DEBUG_PORT` 临时启用本地端口。
- 后端日志：`server/publish.log`（发布链路）、`bridge.log`（IPC）、`music-debug.log`（音乐失败）

## 已知事项

- 音乐"原声"类（title 形如 `@xxx创作的原声`）在音乐面板搜索不到，属抖音平台限制
- 搜索不到目标歌时不盲目点推荐歌，日志记录候选后以无音乐继续发布
- 定时发布为本地定时（每 30s 扫描），不依赖抖音平台定时
- 点击发布前先持久化发布意图；中断遗留任务恢复为“结果未知”，必须人工确认后才能重试，避免重复作品
